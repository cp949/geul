# 20260824-03 표 명령 selection 복구(#109·#110)

- 레인: ff-workflow (트랙 0~8)
- 대상 이슈: #109(종료), #110(종료)
- 작업 브랜치: `fix/109-110-table-command-selection-recovery`(`dev` ff-only 이전 후 삭제)

## 목표

`packages/core/src/table-commands.ts`의 `applyTableGridOperation`을 selection 복구 옵션 없이 호출하던 두 결함을 처리한다. 둘 다 `20260824-02`(#16·#23·#28)가 남긴 후속이다.

- **#109** — `resizeTableColumn`이 `{ preserveSelection: true }`를 전달하지 않아 열 너비 조절 후 캐럿/CellSelection이 예측 불가 위치로 이동.
- **#110** — `insertTableRow`가 공개 API(`editor-controller.ts`) 경로에서 `selectCellId`를 전달받지 못해 행 삽입 후 캐럿이 예측 불가 위치로 이동. Tab 키 경로(`table-keyboard-extension.ts`)만 자체 콜백으로 우회하고 있었다.

## 확정 커밋 해시

| `312a1ac` | fix(table): insertTableRow에 기본 selectCellId를 내장한다 |

작업 브랜치 커밋 2개를 그대로 2개 그룹으로 재조립했다 — 이미 DELTA 경계(#109/#110)와 의미 단위였고 상쇄 쌍이 없었다(`refs/backup/<브랜치>-pre-squash` 대비 트리 diff 2회 모두 빈 출력). 기준선은 `c297e40`, `dev`는 fast-forward됐다.

## 바꾼 계약과 파일

공개 계약 변경 — `insertTableRow`의 `options?: { selectCellId? }` 매개변수 제거(TypeScript optional이라 하위 호환, `editor-controller.ts`는 애초에 노출한 적 없어 공개 API 파손 없음).

- `packages/core/src/table-commands.ts` — `resizeTableColumn`에 `{ preserveSelection: true }` 추가(#109). `insertTableRow`에 `selectCellId: (table) => cellIdAtAnchor(table, { row: atIndex, column: 0 })`를 명령 정의에 내장, caller `options` 매개변수 제거(#110).
- `packages/core/src/table-keyboard-extension.ts` — `goToNextTableCellOrInsertRow`(Tab 경로)의 자체 `selectCellId` 콜백 제거, 주석을 "caller가 아니라 명령 정의가 내장한다"로 갱신.
- `packages/core/test/table-commands.test.ts` — 회귀 테스트 3건(CellSelection 유지 1, TextSelection 유지 1, 신규 행 0열 캐럿 이동 1), 46줄 추가.

파일 3개(`+58/-9`).
