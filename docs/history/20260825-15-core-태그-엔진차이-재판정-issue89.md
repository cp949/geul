## 남은 제한

- `table-paste.spec.ts:66,198`, `table-handle.spec.ts:402`는 여전히 미태그다 — clipboard 이벤트 합성 발산의 대표 1건(`:35`)이 대표한다는 판단이나, fixture별 실제 발산 지점이 있다면 3엔진 커버리지 공백이 남을 수 있다.
- `G-UI-001`(바깥 클릭 초점 유지) 계열 3건은 Playwright WebKit에서 발산 없음을 확인했을 뿐, 실제 macOS Safari의 알려진 버튼 클릭 포커스 예외(OS 설정 의존)는 재현하지 않았다.
- WebKit 버튼 클릭 기본 포커스 차이, `@property` 지원 시점 차이 근거는 브라우저 벤더 공개 자료 기반이며 이 저장소 내 실측 재현은 없다.
- `table-cell-selection.spec.ts:34-37`·`table-format.spec.ts:209-215`의 "브라우저 첫 포커스 mousedown" 주석은 이번 재판정 범위 밖이라 검증하지 않았다.

## 절차상 기록

트랙-6(결함 탐지)이 `table-paste.spec.ts:35`·`table-handle.spec.ts:402` 등 clipboard paste 이벤트 합성(`dispatchPaste`) 4건에서 DELTA-01이 파싱 경로(`rehype-parse`)만 보고 합성 자체의 엔진 의존성(과거 Firefox 회귀, `G-TST-001`)을 놓친 MAJOR 결함 1건을 찾아 대표 1건(`:35`)에 `@core`를 복원했다. 트랙-8 재그룹화는 이 복원 커밋을 DELTA-01과 같은 그룹으로 합쳤다 — 같은 줄(`:35`)을 왕복하는 상쇄 쌍이라 그룹 diff에서 해당 줄은 무변경으로 나타나고, 나머지 실제 제거분만 남는다(재조립 시 `git diff`로 직접 확인).
