## 남은 제한

- **#109**(`resizeTableColumn`, 신규 등록) — #16과 같은 결함 패턴(옵션 없는 `applyTableGridOperation` 호출)이지만 이슈 본문의 7개 명령 목록 밖이라 미착수.
- **#110**(`insertTableRow`, 신규 등록) — 형제 명령 5개는 이번에 고쳐졌는데 공개 API 경로의 행 삽입만 옵션 배선이 빠져 있다.
- `preserveSelection: "cells"` 분기의 anchor/head cellId 미발견 폴백 미구현(트리거하는 호출부가 아직 없음), 삭제·이동 후 캐럿 좌표는 clamp만 하고 정교한 보존은 하지 않음 — 둘 다 이번 작업의 계획 시점 Ruling.
- `dispatchAndVerify`는 "dispatch 시점에 항상 docChanged: true"라는 전제에 의존하며 이 전제는 assert되지 않는다(`PIT-0031`) — 현재 4개 프로덕션 호출부는 안전하다.

## 등록한 이슈와 pitfall
