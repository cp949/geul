# 독자 버전형 문서를 저장 원본으로 사용한다

Geul은 Tiptap JSON, ProseMirror state, HTML 또는 BlockNote JSON 대신 `{ formatVersion, revision, blocks }` 독자 문서를 저장 원본으로 사용하고 Tiptap을 비공개 편집 엔진으로 제한한다. 외부 모델을 그대로 저장하면 초기 구현은 단순하지만 엔진 교체, 안정 ID, 포맷 마이그레이션과 독자 입출력 계약이 외부 릴리스에 종속된다. 변환 경계를 유지하는 비용을 감수하고 저장·검증·버전 의미를 프로젝트가 소유함으로써 공개 API와 장기 데이터 형식을 편집 엔진 변경에서 격리한다.

## Consequences

- 모든 저장 가능한 블록, 행, 열과 셀은 안정 ID를 가진다.
- 편집 엔진과 외부 교환 포맷은 독자 문서 경계에서 명시적으로 변환한다.
- 독자 문서가 지원하지 않는 편집 엔진 상태를 저장 포맷에 누출하지 않는다.
